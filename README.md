# calculadora.multifuncional
Calculadora multifuncional desenvolvida no flowgorithm.
É capaz de fazer Programa desenvolvido em Flowgorithm com menu interativo que repete até o usuário escolher encerrar.
Operações disponíveis: Operação, adição, subtração, multiplicação, divisão, potenciação, resto da divisão média entre dois números, área do círculo, fatorial	porcentagem, encerrar.
Estruturas utilizadas: while — mantém o menu ativo até a opção 11
if/else — identifica a opção e executa o cálculo correspondente
