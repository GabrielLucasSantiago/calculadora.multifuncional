# calculadora.multifuncional
Calculadora Multifuncional

Programa desenvolvido em Flowgorithm com menu interativo que repete até o usuário escolher encerrar.

Operações disponíveis
Opção	Operação
1	Adição
2	Subtração
3	Multiplicação
4	Divisão
5	Potenciação
6	Resto da divisão
7	Média entre dois números
8	Área do círculo
9	Fatorial
10	Porcentagem
11	Encerrar
Estruturas utilizadas
while — mantém o menu ativo até a opção 11
if/else — identifica a opção e executa o cálculo correspondente
